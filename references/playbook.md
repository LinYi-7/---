# 原创视频制作方法库

## 选题命题

把“我想讲一个产品/技术”改写成以下句式之一：

- 为了解决一个具体麻烦，我要做出/改造/测试什么？
- 一个看似普通的东西，经过一项可复现测试后会发生什么？
- 一个被放弃、被误解或被忽略的设计，能否在今天重新成立？
- 为了完成一个不太可能的目标，我必须接受哪些限制？

命题应同时具备：生活入口、可见过程、明确结果和不确定性。若四项中缺两项，换题或缩小承诺。

## 叙事引擎

### 工程挑战

结果预告 → 需求与限制 → 方案草图 → 第一次失败 → 修改与代价 → 成品演示 → 结果对生活的意义。

### 长期实验

日常问题 → 提出可测假设 → 设计对照 → 记录时间与异常 → 中途失败 → 最终数据 → 结论边界与实际建议。

### 产品或历史复原

“为什么它消失/被放弃” → 找到原始约束 → 复原关键机制 → 与今天的条件对比 → 新版本演示 → 对创新或选择的判断。

### 生活痛点测试

熟悉但烦人的场景 → 反常识问题 → 建立统一测试规则 → 多轮体验 → 结果可视化 → 给普通人的低成本建议。

## 标题生成器

先围绕同一命题发散 16 个标题，再按五项各 1–5 分评分：承诺清晰度、好奇缺口、可视化程度、观众收益、可兑现性。保留 3 个方向不同的候选：行动型、疑问型、结果型。

避免：堆型号参数、把结论全部提前说完、无证据的“史上最强”、模仿原作者固定前缀、用省略号掩盖没有结果。

## 封面设计

封面优先展示“证据物”，而不是复述标题。常用结构是一人 + 一物 + 一个动作/关系 + 一个冲突。背景保持单一，缩小到手机信息流尺寸仍能辨认主体；文字只有在画面无法表达概念时使用，尽量少于 8 个字。给同一标题做三版：人物主导、装置主导、结果主导，选择最能兑现承诺的一版。

## 前 15 秒与节奏

前 3 秒出现异常、结果或任务；前 8 秒说清观众要看什么；前 15 秒给出规则、限制或失败风险。每 20–40 秒至少出现一次信息变化：新证据、失败、反转、空间变化、数据更新或新的视觉比喻。不要为了“快”切掉必要的因果链。

## 拍摄与声音

滑轨、转台、推拉、匹配剪辑只在能引导视线或解释机制时使用。抽象时间用植物、耗材、日志、刻度或空间变化可视化。工程声、键盘声、开关声和环境声可作为节拍，但音乐不应掩盖口播和关键证据。旁白先写成可核查的句子，再决定是否需要幽默。

## 事实与版权闸门

发布前逐项记录来源、采集日期、样本、测量方法与误差。开源项目须核对许可证、保留作者信息、说明修改范围；外部素材、音乐和图片须有授权或合法引用依据。把“团队原创”“基于开源改造”“商业合作提供”三种状态明确区分。
